# TaskBan

TaskBan is a premium, modern Kanban board and project management tool built with Laravel, Livewire (Volt), and Alpine.js. It features a stunning dark glassmorphic design and a lightning-fast single-page feel.

## Requirements

- PHP 8.2+
- Composer
- Node.js & NPM
- SQLite (or your preferred database)

## Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MihirParmar011/TaskBan.git
   cd taskban
   ```

2. **Install PHP dependencies:**
   ```bash
   composer install
   ```

3. **Install Node dependencies:**
   ```bash
   npm install
   ```

4. **Environment Setup:**
   Copy the example `.env` file and generate an application key:
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

5. **Database Setup:**
   Configure your database in `.env` (it uses SQLite by default) and run the migrations:
   ```bash
   touch database/database.sqlite
   php artisan migrate --seed
   ```

6. **Start the Development Servers:**
   You will need two terminal windows to run both the Laravel backend and the Vite frontend build tool.

   *Terminal 1 (Backend):*
   ```bash
   php artisan serve
   ```

   *Terminal 2 (Frontend Assets):*
   ```bash
   npm run dev
   ```

7. **Access the Application:**
   Open your browser and navigate to `http://localhost:8000`. You can log in using the credentials generated by the seeder, or register a new account.

## Features

- **Modern Glassmorphism UI**: Beautiful gradients and translucent panels.
- **Projects & Kanban Boards**: Create projects, add columns, and manage issues with a drag-and-drop interface.
- **Backlog Management**: View and filter issues by type and priority.
- **Project Settings**: Manage project details, workflow columns, and invite team members.
- **Profile Management**: Update your information and securely change passwords in a perfectly themed layout.
